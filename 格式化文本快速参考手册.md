# 格式化文本快速参考手册

## 🚀 快速索引

| 格式类型 | 数据库表 | SQL类型 | HTML选择器 | 处理器类 |
|---------|---------|---------|-----------|----------|
| **加粗** | spans | `strong`, `textmark` | `strong`, `b` | BoldProcessor |
| **斜体** | spans | `em`, `textmark` | `em`, `i` | ItalicProcessor |
| **下划线** | spans | `u`, `textmark` | `u` | UnderlineProcessor |
| **高亮** | spans | `mark`, `textmark` | `mark` | HighlightProcessor |
| **备注** | spans | `inline-memo` | `span[data-type*="inline-memo"]` | MemoProcessor |
| **标签** | blocks | - | `span[data-type="tag"]` | TagProcessor |
| **TodoList** | blocks | - | `div[data-subtype="t"]` | TodoProcessor |

## 📊 数据库快速查询

### spans表（内联格式）
```sql
-- 查询所有格式化文本
SELECT * FROM spans 
WHERE root_id = "文档ID" 
  AND type IN ('strong', 'em', 'u', 'mark', 'inline-memo') 
ORDER BY block_id, start_offset;

-- 查询特定格式
SELECT * FROM spans WHERE root_id = "文档ID" AND type = "strong";  -- 加粗
SELECT * FROM spans WHERE root_id = "文档ID" AND type = "mark";    -- 高亮
```

### blocks表（块级内容）
```sql
-- 查询标签块
SELECT * FROM blocks WHERE root_id = "文档ID" AND tag IS NOT NULL;

-- 查询Todo块
SELECT * FROM blocks WHERE root_id = "文档ID" AND subtype = "t";
```

## ⚙️ 核心API

### 1. 数据提取
```typescript
// 解析文档格式化文本
const parser = new TextFormatParser();
const items = await parser.parseFormattedTexts(rootBlockId, {
    enabledFormats: [TextFormatType.BOLD, TextFormatType.HIGHLIGHT],
    maxResults: 200,
    includeContext: true
});
```

### 2. 格式处理器
```typescript
// 获取处理器
const processor = FormatProcessorFactory.getProcessor(TextFormatType.BOLD);

// 从span提取
const items = processor.extractFromSpan(spanData, blockId);

// 从HTML提取
const items = processor.extractFromHTML(htmlString, blockId);
```

## 🎯 常用数据结构

### FormattedTextItem
```typescript
interface FormattedTextItem {
    id: string;              // 唯一ID
    text: string;            // 显示文本
    type: TextFormatType;    // 格式类型
    blockId: string;         // 块ID
    position: number;        // 位置
    context: string;         // 上下文
    icon: string;            // 图标
    color: string;           // 颜色
    memoContent?: string;    // 备注内容
    element?: HTMLElement;   // DOM元素
    metadata?: any;          // 元数据
}
```

### FormatConfig
```typescript
interface FormatConfig {
    sqlType: string[];         // SQL查询类型
    htmlSelectors: string[];   // HTML选择器
    kramdownRegex: RegExp;     // 正则表达式
    icon: string;              // 图标
    color: string;             // 颜色
    displayMode: DisplayMode;  // 显示模式
}
```

## 🔧 自定义格式处理器

### 基本模板
```typescript
export class CustomProcessor extends BaseFormatProcessor {
    public readonly formatType = TextFormatType.CUSTOM;
    
    protected readonly config: FormatConfig = {
        sqlType: ["custom"],
        htmlSelectors: ["span.custom"],
        kramdownRegex: /~~(.+?)~~/g,
        icon: "iconCustom",
        color: "#ff5733",
        displayMode: DisplayMode.SIMPLE
    };
    
    // 可选：自定义渲染
    public renderMainContent(item: FormattedTextItem): string {
        return `<span class="custom">${item.text}</span>`;
    }
}
```

### 注册处理器
```typescript
FormatProcessorFactory.registerProcessor(TextFormatType.CUSTOM, CustomProcessor);
```

## 📊 性能建议

### 查询优化
- 使用索引字段（root_id, type）
- 限制结果数量（LIMIT）
- 避免复杂的JOIN操作

### 渲染优化
- 使用防抖处理频繁更新
- 批量DOM操作
- 虚拟滚动处理大量数据

### 内存管理
- 及时清理事件监听器
- 使用WeakMap存储临时数据
- 定期清理缓存

## 🔍 常见问题

### Q: 格式文本不显示？
A: 检查SQL类型配置和HTML选择器是否正确匹配思源笔记的结构。

### Q: Todo状态更新失败？
A: 确认块ID正确，检查事务API权限和数据格式。

### Q: 自定义处理器不工作？
A: 验证处理器是否正确注册到FormatProcessorFactory。

### Q: 性能问题？
A: 启用缓存、限制查询结果数量、使用防抖处理。
