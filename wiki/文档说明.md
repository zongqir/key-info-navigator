## 🔍 SQL查询完整覆盖

### spans表查询（内联格式）
```sql
-- 所有内联格式的通用查询模板
SELECT * FROM spans 
WHERE root_id = "文档ID" 
  AND type IN ('strong', 'em', 'u', 'mark', 'inline-memo') 
ORDER BY block_id, start_offset 
LIMIT 200;
```

### blocks表查询（块级内容）
```sql
-- 标签块查询
SELECT * FROM blocks WHERE root_id = "文档ID" AND tag IS NOT NULL;

-- Todo块查询  
SELECT * FROM blocks WHERE root_id = "文档ID" AND subtype = "t";
```

## 🖥️ 界面关联说明

### 数据流转换过程
1. **数据库查询** → SQL结果集
2. **格式处理器** → FormattedTextItem对象
3. **UI渲染器** → HTML字符串
4. **事件处理器** → 用户交互绑定
5. **导航器** → 点击跳转功能

### 关键组件关系
```
TextFormatParser (核心解析器)
    ├── BoldProcessor (加粗处理)
    ├── MemoProcessor (备注处理)  
    ├── TodoProcessor (Todo处理)
    ├── TagProcessor (标签处理)
    └── ... (其他处理器)

FormattedTextDock (主容器)
    ├── FormattedTextUIRenderer (UI渲染)
    ├── FormattedTextEventHandler (事件处理)
    ├── FormattedTextNavigator (导航功能)
    └── FormattedTextMemoManager (备注管理)
```
