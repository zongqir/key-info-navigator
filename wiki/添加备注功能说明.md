# 添加备注功能实现说明

## 🎯 功能概述

为格式化文本导航器添加了"为文本添加备注"功能，用户可以直接从侧边栏中为任何格式化文本（加粗、斜体、下划线、高亮）添加备注，调用思源笔记的原生备注功能。

## 🔧 实现架构

### 1. 多态接口扩展

```typescript
export interface IFormatProcessor {
    // ... 原有方法
    
    /** 是否支持添加备注功能 */
    supportAddMemo?(): boolean;
    
    /** 渲染操作按钮（如添加备注按钮） */
    renderActionButtons?(item: FormattedTextItem, i18n?: any): string;
}
```

### 2. 基类默认实现

```typescript
// BaseFormatProcessor.ts
public supportAddMemo(): boolean {
    return true; // 默认支持添加备注
}

public renderActionButtons(item: FormattedTextItem, i18n?: any): string {
    if (!this.supportAddMemo()) {
        return '';
    }
    
    return `
        <button class="formatted-text-dock__add-memo-btn" 
                data-block-id="${item.blockId}"
                data-text="${item.text}"
                title="${i18n?.addMemo || '添加备注'}">
            <svg><use xlink:href="#iconMessage"></use></svg>
        </button>
    `;
}
```

### 3. 备注处理器特殊处理

```typescript
// MemoProcessor.ts
public supportAddMemo(): boolean {
    return false; // 备注本身不需要再添加备注
}
```

```typescript
private triggerAddMemo(protyle: any) {
    // 策略1: 通过工具栏按钮触发
    if (protyle.toolbar?.element) {
        const memoButton = protyle.toolbar.element.querySelector('[data-type="inline-memo"]');
        if (memoButton) {
            memoButton.click(); // ✅ 最可靠的方法
            return;
        }
    }
    
    // 策略2: 通过protyle API触发
    if (protyle.toolbar?.setInlineMark) {
        protyle.toolbar.setInlineMark(protyle, 'inline-memo', 'range');
        return;
    }
    
    // 策略3: 通过事件触发
    // 策略4: 快捷键触发
    // 最后: 提示用户手动操作
}
```

## 📱 用户体验

### 1. 操作步骤

1. **打开侧边栏**：查看格式化文本列表
2. **悬停显示**：鼠标悬停在项目上显示操作按钮
3. **点击添加**：点击备注图标按钮
4. **自动选中**：文本自动被选中
5. **触发功能**：自动触发思源的备注添加对话框
6. **输入内容**：在弹出的对话框中输入备注内容

### 2. 视觉效果

```
🔹 [加粗图标] 重要文本内容              [💬]  ← 悬停时显示
🔸 [斜体图标] 强调文字                 [💬]
📝 [备注图标] 已有备注的文字                  ← 无添加按钮
   💬 这是备注内容...
```

### 3. 交互反馈

- **悬停效果**：按钮淡入显示
- **点击效果**：按钮缩放动画
- **成功提示**：绿色成功消息
- **失败提示**：橙色提示消息指导手动操作

## 🔗 与原生功能集成

### 1. 复用原生UI

- 不重复造轮子，直接调用思源的备注添加对话框

- **回退方案**：提示用户手动操作

### 3. 错误处理

## 🎯 使用指南

### 1. 基本使用

1. 打开包含格式化文本的文档
2. 鼠标悬停在侧边栏的格式化文本项上
3. 点击出现的备注按钮（💬图标）
4. 在弹出的对话框中输入备注内容

### 2. 注意事项

- 备注项本身不显示添加备注按钮
- 添加备注前会自动选中对应的文本
- 如果自动触发失败，会提示手动操作方式
- 支持快捷键 `Ctrl+Shift+M` 备用操作

### 3. 扩展性

- 基于多态设计，易于添加新的操作功能
- 每种格式类型可以自定义操作按钮
- 统一的UI样式和交互逻辑

这个实现完美地集成了思源原生的备注功能，同时保持了代码的模块化和可扩展性，为未来添加更多操作功能打下了良好基础。
