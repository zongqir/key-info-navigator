# 多态显示模式设计实现

## 🎯 需求分析

根据用户要求，实现了多态的显示模式系统：

1. **基础格式类型**（加粗、斜体、下划线、高亮）：只显示提取内容，不显示整个块
2. **备注类型**：特殊显示，要备注的内容在上面，备注内容在下面，去掉整个块显示
3. **扩展性**：为后续添加 TODO、mark 等类型预留接口

## 🏗️ 架构设计

### 1. 显示模式枚举

```typescript
export enum DisplayMode {
    /** 简单模式 - 只显示提取内容 */
    SIMPLE = "simple",
    /** 详细模式 - 显示内容+说明 */
    DETAILED = "detailed", 
    /** 自定义模式 - 完全自定义显示 */
    CUSTOM = "custom"
}
```

### 2. 扩展格式配置接口

```typescript
export interface FormatConfig {
    // ... 原有属性
    /** 显示模式 */
    displayMode: DisplayMode;
}
```

### 3. 扩展处理器接口

```typescript
export interface IFormatProcessor {
    // ... 原有方法
    /** 渲染项目详细内容（用于自定义显示） */
    renderItemDetails?(item: FormattedTextItem, displayText: string): string;
}
```

## 📊 各类型配置

### 基础格式类型（SIMPLE模式）

```typescript
// 加粗、斜体、下划线、高亮
protected readonly config: FormatConfig = {
    // ... 其他配置
    displayMode: DisplayMode.SIMPLE, // 简单模式，只显示内容
};
```

**效果**：只显示格式化的文本内容，不显示任何额外信息

### 备注类型（CUSTOM模式）

```typescript
// 备注处理器
protected readonly config: FormatConfig = {
    // ... 其他配置
    displayMode: DisplayMode.CUSTOM, // 自定义模式
};

// 自定义渲染方法
public renderItemDetails(item: FormattedTextItem, displayText: string): string {
    return `
        <div class="formatted-text-dock__item-memo">
            <div class="formatted-text-dock__item-memo-target">
                ${escapeHtml(displayText)}
            </div>
            <div class="formatted-text-dock__item-memo-content">
                ${escapeHtml(truncateText(item.memoContent, 150))}
            </div>
        </div>
    `;
}
```

**效果**：
- 上方显示：要备注的文本内容（橙色左边框）
- 下方显示：备注的实际内容（灰色边框，略透明）

## 🔧 多态渲染实现

### UI层多态分发

```typescript
private renderItemDetails(item: FormattedTextItem, displayText: string): string {
    const processor = this.parser.getFormatProcessor(item.type);
    const config = processor.getConfig();
    
    switch (config.displayMode) {
        case 'simple':
            return ''; // 不显示额外信息
            
        case 'detailed':
            return /* 显示上下文 */;
            
        case 'custom':
            // 使用处理器的自定义渲染
            if (processor.renderItemDetails) {
                return processor.renderItemDetails(item, displayText);
            }
            return '';
    }
}
```

## 🚀 扩展能力

### 1. 添加新格式类型

```typescript
// 例如：TODO类型
export class TodoProcessor extends BaseFormatProcessor {
    protected readonly config: FormatConfig = {
        sqlType: ["todo"],
        htmlSelectors: ["span[data-type='todo']"],
        kramdownRegex: /- \[ \] (.+)/g,
        icon: "iconTodo",
        color: "#4caf50",
        displayMode: DisplayMode.CUSTOM, // 使用自定义显示
    };
    
    // 自定义渲染
    public renderItemDetails(item: FormattedTextItem, displayText: string): string {
        return `
            <div class="formatted-text-dock__item-todo">
                <div class="todo-status">
                    ${item.completed ? '✅' : '⏳'} ${displayText}
                </div>
                <div class="todo-details">
                    ${item.dueDate || '无截止日期'}
                </div>
            </div>
        `;
    }
}
```

### 2. 工厂自动识别

```typescript
// FormatProcessorFactory 会自动处理新类型
switch (type) {
    case TextFormatType.TODO:
        return new TodoProcessor(logger);
    // ...
}
```

### 3. UI层自动适配

由于多态设计，UI层无需修改即可支持新的格式类型

## 📈 设计优势

### 1. 完全多态
- 每种格式类型独立定义显示逻辑
- UI层通过接口统一调用
- 新增类型无需修改核心代码

### 2. 用户需求满足
- ✅ 基础格式：只显示内容，简洁清晰
- ✅ 备注格式：分层显示，层次分明
- ✅ 无冗余信息：去掉了整个块的显示

### 3. 高度可扩展
- 支持三种显示模式覆盖所有场景
- 自定义渲染方法支持完全个性化
- 配置化设计便于维护

### 4. 向后兼容
- 现有格式类型无缝迁移
- 不破坏原有功能
- 渐进式增强
