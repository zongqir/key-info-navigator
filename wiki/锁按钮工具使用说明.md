## 🔧 API 参考

### 1. `getCurrentActiveReadonlyButton()`

获取当前激活文档的锁按钮

**函数签名**:
```typescript
function getCurrentActiveReadonlyButton(): HTMLElement | null
```

**返回值**:
- `HTMLElement` - 找到的锁按钮元素
- `null` - 未找到锁按钮

**实现方式**（v1.3.0+）:
使用思源官方 `getActiveEditor(false)` API（v3.3.0+）：
- 参数 `false`: 不限制活跃窗口，根据激活时间查找最合适的编辑器
- 优先级：选区 > 活跃窗口 > 最近激活时间
- 支持桌面版和移动版（移动版更简单可靠）

**桌面版**: 多策略查找（选区、活跃窗口、激活时间）  
**移动版**: 直接返回 `mobile.popEditor || mobile.editor`（100%准确）

**使用示例**:
```typescript
import { getCurrentActiveReadonlyButton } from '@/modules/utils';

const readonlyBtn = getCurrentActiveReadonlyButton();
if (readonlyBtn) {
    console.log('找到锁按钮:', readonlyBtn);
    const iconHref = readonlyBtn.querySelector('use')?.getAttribute('xlink:href');
    console.log('图标:', iconHref);
} else {
    console.log('未找到锁按钮');
}
```

### 2. `isCurrentDocumentReadonly()`

检查当前文档是否只读（已锁定）

**函数签名**:
```typescript
function isCurrentDocumentReadonly(): boolean
```

**返回值**:
- `true` - 只读模式（已锁定🔒）
- `false` - 可编辑模式（已解锁✏️）或未找到锁按钮

**判断逻辑**（优先使用 data-subtype）:
```typescript
// 判断逻辑：
// 1. 如果有 data-subtype 属性，优先使用（更准确）
//    - "unlock" → 已解锁（可编辑）
//    - 其他值 → 已锁定（只读）
// 2. 否则根据图标判断（兜底方案）
//    - iconHref !== "#iconUnlock" → 已锁定（只读）

let isReadonly: boolean;

if (subtype) {
    // 优先使用 data-subtype
    isReadonly = subtype !== 'unlock';
} else {
    // 兜底使用图标判断
    isReadonly = iconHref !== '#iconUnlock';
}
```

**使用示例**:
```typescript
import { isCurrentDocumentReadonly } from '@/modules/utils';

if (isCurrentDocumentReadonly()) {
    console.log('🔒 当前文档已锁定（只读模式）');
    // 可以显示高亮工具栏、标签面板等
} else {
    console.log('✏️ 当前文档可编辑（已解锁）');
    // 隐藏工具栏，阻止操作
}
```

### 3. `isCurrentDocumentEditable()`

检查当前文档是否可编辑（已解锁）

**函数签名**:
```typescript
function isCurrentDocumentEditable(): boolean
```

**返回值**:
- `true` - 可编辑（已解锁🔓）
- `false` - 只读（已锁定🔒）或未找到锁按钮

**使用示例**:

## 🎨 使用场景

### 场景1: 显示工具栏前检查

```typescript
import { getCurrentActiveReadonlyButton } from '@/modules/utils';

// 在显示工具栏前检查只读状态
const handleSelection = () => {
    const readonlyBtn = getCurrentActiveReadonlyButton();
    
    if (!readonlyBtn) {
        return; // 未找到锁按钮，不显示工具栏
    }
    
    const iconHref = readonlyBtn.querySelector('use')?.getAttribute('xlink:href') || '';
    const isDocReadonly = iconHref !== '#iconUnlock';
    
    if (!isDocReadonly) {
        return; // 文档可编辑，不显示工具栏
    }
    
    // 显示工具栏...
};
```

### 场景2: 点击高亮/标签前检查

```typescript
import { isCurrentDocumentReadonly } from '@/modules/utils';

// 点击高亮文本时检查
const showDeleteDialog = (highlightElement: HTMLElement) => {
    const isDocReadonly = isCurrentDocumentReadonly();
    
    if (!isDocReadonly) {
        Logger.log('⛔ 文档未锁定，不显示删除对话框');
        return;
    }
    
    Logger.log('✅ 文档已锁定，显示删除对话框');
    // 显示删除对话框...
};
```

### 场景3: 执行写入操作前的兜底防御

```typescript
import { isCurrentDocumentEditable, getCurrentActiveReadonlyButton } from '@/modules/utils';

// 强制解锁前的兜底检查
const forceUnlock = async () => {
    // 兜底防御
    if (isCurrentDocumentEditable()) {
        Logger.error('🛡️ 兜底防御：文档可编辑，拒绝操作');
        throw new Error('文档未锁定，禁止操作');
    }
    
    // 获取锁按钮并点击解锁
    const readonlyBtn = getCurrentActiveReadonlyButton();
    if (!readonlyBtn) {
        throw new Error('未找到锁按钮');
    }
    
    readonlyBtn.click();
    await new Promise(resolve => setTimeout(resolve, 100));
};
```

## 🔄 迁移指南

### 从旧的实现迁移

#### 旧代码（❌ 不推荐）:
```typescript
// 各个文件中重复的实现
private getCurrentActiveReadonlyButton(): HTMLElement | null {
    const readonlyBtn = document.querySelector('.protyle-breadcrumb button[data-type="readonly"]');
    return readonlyBtn as HTMLElement;
}

private checkDocumentReadonly(): boolean {
    const readonlyBtn = this.getCurrentActiveReadonlyButton();
    if (!readonlyBtn) return false;
    
    const iconHref = readonlyBtn.querySelector('use')?.getAttribute('xlink:href') || '';
    return iconHref !== '#iconUnlock';
}
```

#### 新代码（✅ 推荐）:
```typescript
import { getCurrentActiveReadonlyButton, isCurrentDocumentReadonly } from '@/modules/utils';

// 直接使用统一的工具函数
const readonlyBtn = getCurrentActiveReadonlyButton();
const isReadonly = isCurrentDocumentReadonly();
```

### 向下兼容

如果你的代码使用了 `DocumentReadonlyChecker`，无需修改，它现在内部使用新的工具类：

```typescript
import { DocumentReadonlyChecker } from '@/modules/utils';

// 仍然可以使用（向下兼容）
const isReadonly = DocumentReadonlyChecker.checkDocumentReadonly();

// 但建议改为直接使用新工具（更简洁）
import { isCurrentDocumentReadonly } from '@/modules/utils';
```

## 🐛 常见问题

### Q1: 为什么有时候拿不到锁按钮？

**A**: 可能的原因：
1. 当前没有打开的文档
2. 面包屑尚未渲染完成
3. 在特殊的视图下（如搜索、数据库等）

**解决方法**: 总是检查返回值是否为 `null`

```typescript
const readonlyBtn = getCurrentActiveReadonlyButton();
if (!readonlyBtn) {
    Logger.warn('未找到锁按钮，可能当前没有打开文档');
    return;
}
```

### Q2: 多tab场景下如何确保准确？

**A**: v1.3.0 使用官方 `getActiveEditor(false)` API，完美支持多tab：

```typescript
// 工具类已经使用官方API，直接使用即可
const readonlyBtn = getCurrentActiveReadonlyButton();

// 如果开启调试日志，可以看到详细的查找过程
KeyInfoNavigator.enableDebug();
KeyInfoNavigator.getReadonlyButton();

// 日志输出示例：
// 🔍 [ReadonlyButton] getActiveEditor 返回: { protyle: {...} }
// 🔍 [ReadonlyButton] protyle: { element: {...} }
// 🔍 [ReadonlyButton] 找到的按钮: <button>...</button>
```

### Q3: 如何判断解锁状态？

**A**: v1.3.0 优先使用 `data-subtype` 属性判断：

```typescript
// 优先使用 data-subtype（更准确直接）
if (subtype) {
    isReadonly = subtype !== 'unlock';  // "unlock" = 已解锁
} else {
    // 兜底使用图标判断
    isReadonly = iconHref !== '#iconUnlock';
}

// 判断依据优先级：
// 1. data-subtype ✅（首选）
// 2. iconHref ⚠️（兜底）
```
