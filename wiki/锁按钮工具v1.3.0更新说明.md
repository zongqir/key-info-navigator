# 锁按钮工具 v1.3.0 更新说明

**更新日期**: 2025-10-02  
**版本**: v1.3.0  
**类型**: 重要更新 / 优化

---

## 🎯 更新概述

v1.3.0 版本使用思源官方 `getActiveEditor(false)` API 替代了之前的多策略查找实现，代码更简洁，准确性更高。

---

## ✨ 主要更新

### 1. 使用官方 API 获取锁按钮

**之前（v1.2.x）**：
```typescript
// 使用4层策略查找
// 1. 尝试 getActiveTab() API
// 2. 通过焦点元素查找
// 3. 查找活跃窗口
// 4. 全局查找（兜底）
export function getCurrentActiveReadonlyButton(): HTMLElement | null {
    // ... 约100行代码
}
```

**现在（v1.3.0）**：
```typescript
// 直接使用官方 getActiveEditor(false) API
import { getActiveEditor } from 'siyuan';

export function getCurrentActiveReadonlyButton(): HTMLElement | null {
    const currentEditor = getActiveEditor(false);
    const readonlyButton = currentEditor?.protyle?.element?.querySelector(
        ".protyle-breadcrumb > button[data-type='readonly']"
    ) as HTMLButtonElement;
    
    return readonlyButton;
}
```

**改进**：
- ✅ 代码减少约 70%
- ✅ 使用官方API，更可靠
- ✅ 完美支持桌面版和移动版
- ✅ 跟随思源版本更新

---

### 2. 优先使用 data-subtype 判断状态

**之前（v1.2.x）**：
```typescript
// 使用3个条件判断
const isUnlocked = 
    dataSubtype === 'unlock' || 
    ariaLabel.includes('取消') ||
    iconHref === '#iconUnlock';

const isReadonly = !isUnlocked;
```

**现在（v1.3.0）**：
```typescript
// 优先使用 data-subtype
if (subtype) {
    // 首选：data-subtype 判断
    isReadonly = subtype !== 'unlock';
} else {
    // 兜底：图标判断
    isReadonly = iconHref !== '#iconUnlock';
}
```

**改进**：
- ✅ 优先级更明确
- ✅ 判断更直接准确
- ✅ 兜底方案更可靠
