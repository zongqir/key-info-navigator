# 控制台调试功能说明

## 功能概述

插件现在支持通过浏览器控制台：
1. **动态控制调试日志开关**（默认关闭）
2. **检查文档只读状态**（实时查看当前文档是否锁定）

## 使用方法

打开浏览器开发者工具（F12），在控制台中输入以下命令。

---

## 一、调试日志控制

### 1. 查看调试日志状态
```javascript
KeyInfoNavigator.getDebugStatus()
```
返回示例：
```javascript
{
  enabled: false,
  message: "调试日志: 关闭 🔇 (仅输出错误信息)"
}
```

### 2. 开启调试日志
```javascript
KeyInfoNavigator.enableDebug()
```
返回：`"调试日志已开启 ✅"`

### 3. 关闭调试日志
```javascript
KeyInfoNavigator.disableDebug()
```
返回：`"调试日志已关闭 🔇"`

### 4. 切换调试模式（开/关）
```javascript
KeyInfoNavigator.toggleDebug()
```
返回：`"调试日志已开启"` 或 `"调试日志已关闭"`

---

## 二、文档状态检查工具（新增✨）

### 1. 检查当前文档只读状态（推荐）
```javascript
KeyInfoNavigator.checkDocStatus()
```
返回详细信息：
```javascript
{
  hasButton: true,
  isReadonly: true,
  isEditable: false,
  ariaLabel: "临时锁定",
  dataSubtype: "lock",
  iconHref: "#iconLock",
  statusText: "文档已锁定🔒（只读模式）"
}
```

### 2. 快速检查是否只读
```javascript
KeyInfoNavigator.isReadonly()
```
输出并返回：`true` (已锁定) 或 `false` (已解锁)

### 3. 快速检查是否可编辑
```javascript
KeyInfoNavigator.isEditable()
```
输出并返回：`true` (可编辑) 或 `false` (只读)

### 4. 获取当前文档的锁按钮
```javascript
KeyInfoNavigator.getReadonlyButton()
```
返回锁按钮元素，并在控制台输出按钮属性

## 特性

- ✅ **默认关闭**：插件启动时默认不输出调试日志，减少内存占用
- ✅ **持久化保存**：调试开关状态会被保存，重启思源后保持上次的设置
- ✅ **实时生效**：无需重启插件，立即生效
- ✅ **错误日志始终显示**：即使关闭调试日志，错误信息仍会输出到控制台
- ✅ **友好提示**：插件加载时会在控制台显示可用命令和当前状态

## 注意事项

1. 调试日志关闭时，只有错误日志（`Logger.error`）会输出到控制台
2. 开启调试日志后，会输出所有级别的日志（log、info、warn、debug、error）
3. 设置会自动保存在插件的配置文件中（`settings.json`）

## 调试技巧

当遇到问题时，建议：
1. 先开启调试日志：`KeyInfoNavigator.enableDebug()`
2. 重现问题操作
3. 查看控制台的详细日志输出
4. 调试完成后关闭：`KeyInfoNavigator.disableDebug()`
