## 工作原理

### 数据流程

```
1. FormattedTextDock.loadFormattedTexts()
   ↓
2. TextFormatParser.parseFormattedTexts()
   ↓
3. 查询数据库（Tag、Todo、Spans）
   ↓
4. 收集所有 FormattedTextItem
   ↓
5. SorterFactory.getDefaultSorter() ← 获取渲染顺序排序器
   ↓
6. RenderOrderSorter.sort(items) ← 执行排序
   ├─ 优先：从 DOM 获取块的渲染位置
   └─ 降级：从数据库查询块的创建时间
   ↓
7. 返回排序后的 items
   ↓
8. FormattedTextUIRenderer.createListHTML() ← 渲染（保持顺序）
```

### 排序逻辑详解

**RenderOrderSorter（渲染顺序排序器）：**

1. **提取唯一块ID**
   - 从所有 items 中提取唯一的 blockId

2. **获取块位置**
   - **方法1（优先）：** 从 DOM 中查找 `[data-node-id]` 元素，记录其在文档中的索引
   - **方法2（降级）：** 如果 DOM 不可用，从数据库查询块的 `created` 时间作为位置参考

3. **排序规则**
   - 不同块：按块的位置排序
   - 同一块：按 `position` 字段排序
   - 无位置信息：使用 `blockId` 字符串排序作为后备

## 默认配置

**当前默认排序：** 渲染顺序（RENDER_ORDER）

这意味着：
- ✅ 列表顺序与文档中块的实际渲染位置一致
- ✅ 用户看到的顺序符合文档阅读习惯
- ✅ 自动适配不同的环境（DOM 可用或不可用）

可以在侧边栏添加一个下拉菜单，让用户选择排序方式：

```typescript
// 在 FormattedTextDock.ts 中添加
private currentSortStrategy: SortStrategy = SortStrategy.RENDER_ORDER;

// 添加UI控件
private createSortSelector(): HTMLElement {
    const select = document.createElement('select');
    select.innerHTML = `
        <option value="${SortStrategy.RENDER_ORDER}">渲染顺序</option>
        <option value="${SortStrategy.BLOCK_ID}">Block ID</option>
        <option value="${SortStrategy.UPDATE_TIME}">更新时间</option>
    `;
    
    select.addEventListener('change', async (e) => {
        const target = e.target as HTMLSelectElement;
        this.currentSortStrategy = target.value as SortStrategy;
        await this.loadFormattedTexts(true); // 重新加载并排序

    return select;
```

## 常见问题

### Q1: 为什么列表顺序与预期不符？

**A:** 检查以下几点：
1. DOM 是否正确加载（查看控制台日志）
2. 块是否有正确的 `data-node-id` 属性
3. 数据库中的 `created` 时间是否准确

### Q2: 排序性能如何？

**A:** 
- 小于 100 个项目：< 10ms
- 100-500 个项目：< 50ms
- 500+ 个项目：< 100ms

### Q3: 如何切换到其他排序方式？

**A:** 在代码中修改：
```typescript
// 将默认排序改为 Block ID 排序
const sorter = SorterFactory.getSorter(SortStrategy.BLOCK_ID);

// 或改为更新时间排序
const sorter = SorterFactory.getSorter(SortStrategy.UPDATE_TIME);
```

### Q4: 排序器是否会修改原始数据？

**A:** 不会。排序器总是返回新的数组，不修改原始数据。
