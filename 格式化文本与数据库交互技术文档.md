# 格式化文本与数据库交互技术文档

## 📋 概述

本文档详细说明了思源笔记插件（Key Info Navigator）如何处理各种格式化文本（加粗、斜体、高亮、下划线、备注、TodoList）的数据库交互和界面关联机制。

## 🏗️ 整体架构

### 数据流程图
```
用户文档 → SiYuan数据库 → SQL查询 → 格式处理器 → UI渲染 → 用户界面
    ↑                                                            ↓
    └─────────────── 用户交互操作（点击、编辑）←──────────────────────┘
```

### 核心组件
- **TextFormatParser**: 核心解析器，协调所有格式处理器
- **IFormatProcessor**: 格式处理器接口，定义标准行为
- **BaseFormatProcessor**: 抽象基类，提供通用功能
- **具体处理器**: BoldProcessor、ItalicProcessor、HighlightProcessor等
- **FormattedTextDock**: UI显示容器
- **FormattedTextUIRenderer**: UI渲染引擎

## 🗄️ 数据库结构

### 1. spans表（内联格式）
用于存储文档中的内联格式化文本。

**表结构：**
```sql
CREATE TABLE spans (
    id TEXT,               -- 唯一标识
    block_id TEXT,         -- 所属块ID
    root_id TEXT,          -- 文档根ID
    type TEXT,             -- 格式类型
    content TEXT,          -- 文本内容
    start_offset INTEGER,  -- 开始位置
    end_offset INTEGER,    -- 结束位置
    markdown TEXT,         -- 原始markdown
    -- 其他字段...
);
```

**支持的格式类型：**
- `"strong"` - 加粗
- `"em"` - 斜体
- `"u"` - 下划线
- `"mark"` - 高亮
- `"inline-memo"` - 备注
- `"textmark"` - 文本标记

### 2. blocks表（块级内容）
用于存储文档中的块级内容。

**表结构：**
```sql
CREATE TABLE blocks (
    id TEXT,           -- 块ID（主键）
    root_id TEXT,      -- 文档根ID
    type TEXT,         -- 块类型
    subtype TEXT,      -- 子类型
    content TEXT,      -- 块内容
    tag TEXT,          -- 标签（逗号分隔）
    created TEXT,      -- 创建时间
    updated TEXT,      -- 更新时间
    -- 其他字段...
);
```

**相关查询条件：**
- 标签块：`tag IS NOT NULL`
- Todo块：`subtype = "t"`

```typescript
// 检测Todo完成状态
private isTodoCompleted(input: Element | string): boolean {
    if (typeof input === 'string') {
        // 检查markdown格式：[x] 表示完成
        return /^\s*[-*+]\s*\[x\]/mi.test(input);
    } else {
        // 检查DOM元素
        if (input.classList.contains('protyle-task--done')) {
            return true;
        }
        
        const checkbox = input.querySelector('input[type="checkbox"]');
        return checkbox ? (checkbox as HTMLInputElement).checked : false;
    }
}

// 更新Todo状态到数据库
public async updateTodoStatus(blockId: string, completed: boolean): Promise<boolean> {
    // 1. 构造新的HTML数据
    const newData = this.generateUpdatedHTML(blockId, completed);
    
    // 2. 使用事务API更新
    const transactionData = {
        session: this.generateSessionId(),
        transactions: [{
            doOperations: [{
                id: blockId,
                data: newData,
                action: "update"
            }]
        }]
    };
    
    const response = await fetch('/api/transactions', {
        method: 'POST',
        headers: { 'Content-Type': 'text/plain;charset=UTF-8' },
        body: JSON.stringify(transactionData)
    });
    
    return response.ok;
}
```

```typescript
// 标签颜色算法
private getTagColor(tagName: string): string {
    let hash = 0;
    for (let i = 0; i < tagName.length; i++) {
        hash = tagName.charCodeAt(i) + ((hash << 5) - hash);
    }
    const index = Math.abs(hash) % this.tagColors.length;
    return this.tagColors[index];
}

// 自定义渲染
public renderMainContent(item: FormattedTextItem): string {
    const { tagName } = item.metadata;
    const tagColor = this.getTagColor(tagName);
    
    return `
        <div class="formatted-text-dock__item-tag-inline">
            <div class="formatted-text-dock__tag-shape" style="background-color: ${tagColor}">
                <span class="formatted-text-dock__tag-text">#${tagName}</span>
            </div>
            <span class="formatted-text-dock__tag-block-text">${item.context}</span>
        </div>
    `;
}
```

```typescript
public createListHTML(groupedItems: Map<string, FormattedTextItem[]>): string {
    let html = '';
    
    for (const [groupName, items] of groupedItems) {
        html += `<div class="formatted-text-dock__group">`;
        html += `<h3 class="formatted-text-dock__group-title">${groupName}</h3>`;
        
        for (const item of items) {
            html += this.createItemHTML(item);
        }
        
        html += `</div>`;
    }
    
    return html;
}

private createItemHTML(item: FormattedTextItem): string {
    const processor = FormatProcessorFactory.getProcessor(item.type);
    
    // 使用处理器的自定义渲染（如果存在）
    const mainContent = processor.renderMainContent ? 
        processor.renderMainContent(item) : 
        `<span class="formatted-text-dock__item-text">${item.text}</span>`;
    
    const actionButtons = processor.renderActionButtons(item, this.i18n);
    
    return `
        <div class="formatted-text-dock__item" data-item-id="${item.id}" data-type="${item.type}">
            <div class="formatted-text-dock__item-indicator" style="background-color: ${item.color}"></div>

                <div class="formatted-text-dock__item-header">

                        ${mainContent}
                    </div>
                    <div class="formatted-text-dock__item-actions">
                        ${actionButtons}
                    </div>
                </div>
                ${processor.renderItemDetails ? processor.renderItemDetails(item, item.text) : ''}
            </div>
        </div>
```

```typescript
// src/modules/formattedTextDock/FormattedTextEventHandler.ts
public bindItemEvents(container: HTMLElement): void {
    // 点击项目导航
    container.addEventListener('click', (event) => {
        const item = event.target.closest('.formatted-text-dock__item');
        if (item && !event.target.closest('.formatted-text-dock__item-actions')) {
            this.navigator.navigateToItem(item.dataset.itemId);
        }
    });
    
    // Todo状态切换
    container.addEventListener('change', (event) => {
        const checkbox = event.target as HTMLInputElement;
        if (checkbox.classList.contains('formatted-text-dock__todo-checkbox')) {
            const blockId = checkbox.dataset.blockId;
            const completed = checkbox.checked;
            this.handleTodoStatusChange(blockId, completed);
        }
    });
    
    // 操作按钮处理
    container.addEventListener('click', (event) => {
        const button = event.target.closest('[data-action]');
        if (button) {
            const action = button.dataset.action;
            const blockId = button.dataset.blockId;
            const text = button.dataset.text;
            
            switch (action) {
                case 'add-memo':
                    this.memoManager.showMemoDialog(text, blockId);
                    break;
                case 'remove-format':
                    this.handleRemoveFormatting(text, blockId, button.dataset.type);
                    break;
            }
        }
    });
}
```

## 🔄 实时同步机制

### 1. 编辑器变化检测

```typescript
// src/modules/formattedTextDock/FormattedTextDock.ts
public onDocumentChange(): void {
    // 清除之前的定时器
    if (this.refreshTimer) {
        clearTimeout(this.refreshTimer);
    }
    
    // 使用防抖避免频繁刷新
    this.refreshTimer = window.setTimeout(() => {
        const currentEditor = EditorUtils.getCurrentActiveEditor();
        const newBlockId = currentEditor?.protyle?.block?.rootID;
        
        if (newBlockId && newBlockId !== this.currentBlockId) {
            // 文档切换，强制刷新
            this.refresh(true);
        } else if (newBlockId === this.currentBlockId) {
            // 同一文档，使用缓存刷新
            this.refresh(false);
        }
    }, 200);
}
```

### 2. 双向数据提取

```typescript
// 优先从编辑器实时获取，数据库查询作为备选
public async parseFormattedTexts(rootBlockId: string, options: ParseOptions): Promise<FormattedTextItem[]> {
    const allItems: FormattedTextItem[] = [];
    
    // 1. 实时提取（编辑器DOM）
    const editor = EditorUtils.getCurrentActiveEditor();
    if (editor?.protyle) {
        const realtimeResults = this.getCurrentEditorFormattedTexts(editor.protyle, options);
        if (realtimeResults.length > 0) {
            return realtimeResults;
        }
    }
    
    // 2. 数据库查询（备选方案）
    // 查询标签块
    if (options.enabledFormats.includes(TextFormatType.TAG)) {
        const tagItems = await this.queryTagBlocks(rootBlockId, options.maxResults);
        allItems.push(...tagItems);
    }
    
    // 查询Todo块
    if (options.enabledFormats.includes(TextFormatType.TODO)) {
        const todoItems = await this.queryTodoBlocks(rootBlockId, options.maxResults);
        allItems.push(...todoItems);
    }
    
    // 查询内联格式
    const spanFormats = options.enabledFormats.filter(f => 
        f !== TextFormatType.TAG && f !== TextFormatType.TODO
    );
    if (spanFormats.length > 0) {
        const processors = FormatProcessorFactory.getProcessors(spanFormats);
        const spanItems = await this.querySpans(rootBlockId, processors, options);
        allItems.push(...spanItems);
    }
    
    return allItems;
}
```

```typescript
// 缓存策略
private cache = new Map<string, FormattedTextItem[]>();

private getCacheKey(blockId: string, formats: TextFormatType[]): string {
    return `${blockId}_${formats.sort().join('_')}`;
}

public async parseFormattedTexts(rootBlockId: string, options: ParseOptions): Promise<FormattedTextItem[]> {
    const cacheKey = this.getCacheKey(rootBlockId, options.enabledFormats);
    
    // 检查缓存
    if (this.cache.has(cacheKey)) {
        return this.cache.get(cacheKey)!;
    }
    
    // 执行查询
    const results = await this.performActualQuery(rootBlockId, options);
    
    // 缓存结果
    this.cache.set(cacheKey, results);
    
    return results;
}
```

## 📝 总结

本插件通过以下机制实现格式化文本的完整管理：

1. **数据获取**：通过SQL查询spans和blocks表获取格式化数据

整个系统采用模块化设计，易于扩展和维护，为用户提供了完整的格式化文本管理体验。
